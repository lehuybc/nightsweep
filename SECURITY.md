# Security policy

- **Report a vulnerability** privately (GitHub "Report a vulnerability" / security advisory, or the contact on https://www.nightsweep.xyz/). Please do not open public issues for exploitable bugs.
- **Scope**: the page (`src/`), the proxies (`server/`), and the build.
- **Design rules** (changes must keep them): no seed/private-key input; no third-party scripts by default; proxy allow-lists only the three needed calls; no raw IP or address storage.
- **Official site**: only https://www.nightsweep.xyz/ . Anyone asking for your seed phrase is a scammer.
